# Assets da Play Store

Assets atualizados para a identidade publica **Carteado BR**.

Arquivos principais cobertos:

- `icon-512.png`: PNG 512 x 512 para o ícone da Play Store.
- `feature-graphic-1024x500.png`: PNG 1024 x 500 sem alpha para o gráfico de destaque.
- `screenshots/*.png`: quatro capturas reais em 1920 x 1080: menu, regras, partida e ações.
- `screenshots-phone/*.png`: capturas em formato celular (menu, lobby contra a máquina, partida de Cacheta).

Texto sugerido para a listagem:

- App name: `Carteado BR`
- Short description: `Jogue Cacheta, Buraco e Tranca em partidas de cartas.`
- Full description draft:

```text
Carteado BR é um jogo de cartas em desenvolvimento para partidas locais em modo paisagem.

Crie uma sala na rede local, jogue contra a máquina ou escolha entre Cacheta, Buraco e Tranca com regras configuráveis para cada mesa.

Esta versão prioriza testes práticos da interface, fluxo de sala, placar local, animações e base de regras para evoluir futuramente para partidas online.
```

Antes de publicar em produção:

- Revisar as capturas no aparelho usado para o teste fechado antes de enviar a listagem final.
- Configurar Play App Signing e uma chave privada de upload antes do bundle final.
- Preencher classificação indicativa, segurança de dados, público-alvo, política de privacidade se for exigida, e trilhas de teste no Play Console.
